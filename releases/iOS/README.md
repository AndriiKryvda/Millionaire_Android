# iOS-збірки

У цій папці зберігається **лише найновіша** збірка для iOS (наприклад,
`millionaire-<version>.ipa` або `.zip` з білдом).

iOS-білди не можна зібрати на Windows — їх створюють на macOS з iOS-таргету
проєкту (Compose Multiplatform-модуль `:shared`). Порядок релізу:

1. Зберіть iOS-білд на macOS (Xcode / `./gradlew :shared:iosArm64...` або збірка таргету iOS-обгортки).
2. Покладіть файл сюди, видаливши попередню версію (тут завжди рівно один артефакт).
3. Оновіть посилання на iOS-збірку в головному `README.md`.
